# Vamsi's Tech Blog

Welcome to my personal tech blog where I share insights and learnings about:

- **Artificial Intelligence**: Machine learning, neural networks, and AI applications
- **GitHub Copilot & AI Assistants**: How AI is transforming software development
- **AI Agents**: Understanding autonomous agents and their real-world implementations
- **Cloud Native**: Microservices, containers, Kubernetes, and modern architecture patterns
- **Linux**: System administration, command-line mastery, and open-source tools
- **Microsoft Azure**: Cloud services, architecture patterns, and best practices

## About This Site

This is a GitHub Pages repository hosting my blog at [vamsikavuru.github.io](https://vamsikavuru.github.io). The blog features simple, clean design with a focus on content and readability.

## Structure

- `index.html` - Homepage with blog post listings
- `about.html` - About page with personal introduction
- `styles.css` - Stylesheet for consistent design
- `posts/` - Directory containing individual blog posts

## Technology Stack

- Pure HTML/CSS for simplicity and fast loading
- Responsive design for mobile and desktop
- GitHub Pages for hosting

## Getting Started

To view the site locally:

1. Clone this repository
2. Open `index.html` in your web browser

To deploy changes:

1. Make your edits
2. Commit and push to the main branch
3. GitHub Pages will automatically deploy your changes
