Mastering Linux Command Line

Published on November 12, 2025

The Linux command line is a powerful tool that every developer, system administrator, and DevOps engineer should master. While graphical interfaces are convenient, the command line offers unmatched power, flexibility, and efficiency for managing systems and automating tasks.

Why Learn the Command Line?

Understanding the Linux command line provides several advantages:

  • Faster execution of repetitive tasks through scripting
  • Remote server management via SSH
  • Better understanding of how systems work
  • Ability to troubleshoot issues effectively
  • Automation of complex workflows

Essential File and Directory Commands

Navigation and Listing

  • pwd - Print working directory
  • ls - List directory contents (ls -la for detailed view)
  • cd - Change directory (cd .. to go up one level)
  • tree - Display directory structure as a tree

File Operations

  • touch file.txt - Create an empty file
  • cp source dest - Copy files or directories
  • mv old new - Move or rename files
  • rm file - Remove files (rm -rf dir for directories)
  • mkdir dirname - Create directories
  • rmdir dirname - Remove empty directories

Viewing and Editing Files

  • cat file - Display file contents
  • less file - View file with pagination
  • head -n 10 file - Show first 10 lines
  • tail -n 10 file - Show last 10 lines
  • nano file - Simple text editor
  • vim file - Powerful text editor

Text Processing and Search

Searching

  • grep "pattern" file - Search for patterns in files
  • find /path -name "*.txt" - Find files by name
  • locate filename - Quick file search using database
  • which command - Find command location

Text Manipulation

  • sed 's/old/new/g' file - Stream editor for text transformation
  • awk '{print $1}' file - Pattern scanning and processing
  • cut -d',' -f1 file.csv - Extract columns from delimited files
  • sort file - Sort lines of text
  • uniq file - Remove duplicate lines
  • wc -l file - Count lines, words, characters

System Information and Management

System Information

  • uname -a - System information
  • df -h - Disk space usage
  • du -sh * - Directory size
  • free -h - Memory usage
  • top or htop - Process monitoring
  • uptime - System uptime and load

Process Management

  • ps aux - List all processes
  • kill PID - Terminate a process
  • killall name - Kill processes by name
  • jobs - List background jobs
  • bg and fg - Background and foreground jobs
  • nohup command & - Run command immune to hangups

Networking Commands

  • ping host - Test network connectivity
  • curl url - Transfer data from URLs
  • wget url - Download files from the web
  • ssh user@host - Secure shell login
  • scp file user@host:/path - Secure file copy
  • netstat -tuln - Network statistics
  • ip addr - Show IP addresses

File Permissions and Ownership

  • chmod 755 file - Change file permissions
  • chown user:group file - Change ownership
  • ls -l - View detailed file permissions

Powerful Command Line Features

Pipes and Redirection

  • command1 | command2 - Pipe output to another command
  • command > file - Redirect output to file (overwrite)
  • command >> file - Append output to file
  • command < file - Use file as input
  • command 2>&1 - Redirect stderr to stdout

Command Substitution

  • $(command) - Use command output as argument
  • `command` - Alternative syntax for substitution

Wildcards

  • * - Match any characters
  • ? - Match single character
  • [abc] - Match any character in brackets
  • {txt,pdf} - Match any pattern in braces

Package Management

Debian/Ubuntu (apt)

  • apt update - Update package lists
  • apt upgrade - Upgrade packages
  • apt install package - Install packages
  • apt remove package - Remove packages

Red Hat/CentOS (yum/dnf)

  • yum update - Update packages
  • yum install package - Install packages
  • yum remove package - Remove packages

Shell Scripting Basics

Automate tasks by creating shell scripts. A simple example:

  • Start with #!/bin/bash shebang
  • Use variables: VAR="value"
  • Use conditionals: if [ condition ]; then ... fi
  • Use loops: for item in list; do ... done
  • Make executable: chmod +x script.sh

Tips for Mastery

  • Use man command to read manual pages
  • Use command --help for quick help
  • Practice regularly with real tasks
  • Learn keyboard shortcuts (Ctrl+C, Ctrl+Z, Ctrl+R)
  • Customize your shell with aliases and functions
  • Use tab completion to save time
  • Keep a command cheat sheet handy

Conclusion

Mastering the Linux command line is a journey that pays dividends throughout your career. Start with the basics, practice regularly, and gradually expand your repertoire. The command line's power lies not just in individual commands but in how you combine them to solve complex problems efficiently. Remember, the best way to learn is by doing—so open a terminal and start experimenting!
